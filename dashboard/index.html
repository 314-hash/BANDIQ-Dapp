Documentation & Security Protocol

BANDIQ architecture, operator consent rules, and data collection transparency

1. Safety & Privacy Architecture

  • Never an open relay or botnet: The agent does not allow random internet traffic to enter or exit your home connection unmetered or unauthenticated.
  • No private keys requested: You never share your wallet private key or mnemonic phrase. Only public EVM addresses are associated.
  • No remote shell execution: The agent will never execute arbitrary terminal commands or run executables sent by the backend.
  • Zero browsing history collection: No website URLs, DNS queries, payload contents, or personal files are accessed.

2. Shariah Compliance DePIN Tenets

  • Real Network Service Backing: Rewards correspond strictly to measurable, proven bandwidth capacity and delivered service.
  • No Speculative Fabrications: Zero promises of token price appreciation or guaranteed yield.
  • Clear Consent & Mutual Receipts: Transparent fee structures with no hidden surcharges or unlimited contract token approvals.
